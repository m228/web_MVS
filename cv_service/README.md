# CV-сайдкар — распознавание кристаллов (YOLO-seg)

Отдельный процесс рядом с `web_MVS` (не внутри exe). Крутит обученную модель на GPU,
основное приложение шлёт ему кадры пробы по localhost и получает маски кристаллов.
Разломы считает сам основной app (OpenCV, без этого сервиса).

## Установка на машине распознавания (Буи / Кир)

Каждая машина — свой venv и своя модель. Нужны:
- **Python 3.10+** в PATH (рекомендуется 3.11+, как на тренировочной машине).
- **Драйвер NVIDIA** (проверь `nvidia-smi`). CUDA Toolkit отдельно НЕ нужен — колёса torch тащат свои cuda-длл.
- **Microsoft Visual C++ Redistributable x64** — на голой винде его НЕТ, без него torch падает
  с `WinError 1114 ... c10.dll`. Поставь один раз: https://aka.ms/vs/17/release/vc_redist.x64.exe
- Системный прокси (если интернет через раздающий сервер) `setup.bat` подхватит сам.

1. Поставить Python 3.10+ (в PATH).
2. Запустить **`setup.bat`** — создаст `.venv`, поставит torch-CUDA (cu124) + ultralytics + базу,
   проверит GPU.
3. Положить модель в **`model\best.pt`** (или залить через кнопку в UI, см. ниже).
4. Запустить **`run.bat`** — поднимет сайдкар на `127.0.0.1:8765`.
   Если модели нет — поднимется в режиме `classic` (OpenCV, без GPU), чтобы было видно поток.
5. В web_MVS на вкладке «CV» включить тумблер CV. Статус покажет «онлайн · yolo:best.pt».

> На Буи 1050 Ti (4 ГБ): модель YOLO-seg + SAHI тайлами идёт последовательно, в память влезает.
> Драйвер 581/CUDA13 совместим с колёсами torch cu124.

## Загрузка/смена модели (train локально → на Буи)

Ты обучаешь на своей машине, а на Буи/Кир модель попадает одним из способов:
- **Через UI (удобно):** вкладка «CV» → «Загрузить модель (.pt)» → выбираешь файл в браузере →
  сайдкар сохраняет в `model\` и **горячо** подхватывает (без перезапуска).
- **Вручную:** скопировать `.pt` в `cv_service\model\best.pt`, затем `run.bat` (или кнопка «Загрузить по пути»).

Модель — **сегментация**, 1 класс `crystal`. Размер считается по маске (613.8 px/mm → 1.629 мкм/px).

## Переменные окружения
| Переменная | Смысл | По умолчанию |
|---|---|---|
| `CV_HOST` / `CV_PORT` | адрес/порт | 127.0.0.1 / 8765 |
| `CV_MODEL` | путь к модели (.pt/.onnx) или `classic`, или пусто (заглушка) | — |

## API сайдкара
- `GET /health`, `GET /model` — статус и метаданные модели.
- `POST /model/upload?name=best.pt` — залить .pt (сырые байты), сохранить + загрузить.
- `POST /model/load` {path} — загрузить модель по пути на диске сайдкара.
- `POST /infer?tiles=&conf=&iou=&overlap=` — кадр (сырые байты) → объекты(bbox/маска)+тайминги.

Число тайлов SAHI правится в UI на вкладке «CV» (поле «Тайлов SAHI») на лету: мелкие
кристаллы — больше тайлов, крупные — меньше (1 = без нарезки, по всему кадру).
