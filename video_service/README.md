# Видео-сервис — ролик варки

Отдельный процесс рядом с `web_MVS` (как `cv_service`). Собирает ролик по варке: слева фото пробы с контурами
распознавания, справа рассев (9 групп, как на тренде) и графики среднего размера, муки и СВ, внизу полоса стадий.
1920×1080, H.264 MP4 (играет везде, в Telegram тоже), 0,5 с на пробу, заставка с логотипом и итог в конце.

Из web_MVS ничего не импортирует: читает только папки проб (`cv_results\<серийник>\<ts>\` — `result.json`,
`frame_N.png|jpg`, `objects_N.json`). Папку можно переложить куда угодно, но запускать нужно на том же компе,
где лежат пробы.

## Установка (один раз)

1. Python 3.10+ в PATH.
2. **`setup.bat`** — создаст `.venv` и поставит зависимости (OpenCV, Pillow, FastAPI, ffmpeg через imageio-ffmpeg).
   GPU не нужен. Системный прокси подхватит сам.

На машине с релизным web_MVS (без git) — **`UpdaterVideo.bat`** в папке web_MVS: скачает `video_service_v*.zip`
из последнего релиза в `video_service\` и при первом запуске сам вызовет `setup.bat`. GitHub отдаёт релиз, но файл
не качается — скачать архив на другом компе и `UpdaterVideo.bat -ZipPath "D:\video_service_v….zip"`.

## Запуск

**`run.bat`** — сервис на `127.0.0.1:8767`. В web_MVS на странице микроскопа в нижней полосе появится вкладка
**«Ролик»**: список варок → «Собрать ролик» → прогресс → «Скачать». Готовые ролики лежат в `video_service\video\`.
Сервис не запущен — вкладки нет, web_MVS работает как обычно.

Адрес сервиса меняется в `plate_config.json` → `"video": {"service_url": "http://127.0.0.1:8767"}`.

Ролик можно собрать только по варкам, у которых кадры ещё лежат в архиве проб (по умолчанию последние 10 варок —
поле «Варок в архиве» на вкладке «CV»).

## Проверка без web_MVS

```
.venv\Scripts\python.exe render.py frame <папка с пробами> --probe 80 --out кадр.png
.venv\Scripts\python.exe render.py video <папка с пробами>
```

`--smooth 0` — без сглаживания (по умолчанию рассев, размер и мука сглажены по соседним пробам, σ = 90 с: в начале
варки пробы частые и шумные).

## Эндпоинты

| | |
|---|---|
| `GET /health` | жив, версия, идёт ли сборка |
| `POST /build` | `{"dirs": [папки проб], "name": "файл.mp4"}` → `{"id"}` |
| `GET /jobs/{id}` | `queued / running / done / error`, кадров сделано / всего, имя файла |
| `GET /files` | готовые ролики |
| `GET /file/{name}` | скачать ролик |
