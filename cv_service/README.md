# CV-сайдкар (компьютерное зрение для микроскопа)

Отдельный процесс с детектором кристаллов. Живёт **рядом** с основным `web_MVS` (не внутри
его exe), общается по localhost. Так GPU-стек (torch-cuda) ставится в нормальный venv, а
основной бандл остаётся лёгким и обновляется через (режущийся) CDN без проблем.

## Зачем отдельно
- Основной exe не раздувается на 2 ГБ (torch+CUDA).
- Модель обновляется подменой файла, без пересборки exe.
- Падение/OOM инференса не роняет управление платой и камерой.
- CUDA Toolkit ставить НЕ надо — колёса torch тащат свои cuda-длл; нужен только **драйвер NVIDIA**.

## Установка (машина распознавания, голая винда)

1. Проверь драйвер и GPU:
   ```
   nvidia-smi
   ```
   Если команды нет — поставь драйвер NVIDIA для GTX 1050 Ti. В углу вывода — версия CUDA (потолок драйвера).

2. Заведи venv и поставь зависимости:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Фаза 1 (заглушка, без модели)** — можно запускать сразу, GPU не нужен:
   ```
   python server.py
   ```
   Проверка: открой http://127.0.0.1:8765/health — должен ответить `"stub": true`.

4. **Фаза 8 (реальная модель, GPU)** — добавь GPU-пакеты и модель:
   ```
   pip install ultralytics
   pip install torch --index-url https://download.pytorch.org/whl/cu124
   ```
   Положи обученную seg-модель в `model/best.pt` и запусти с указанием пути:
   ```
   set CV_MODEL=model\best.pt
   python server.py
   ```

## Переменные окружения
| Переменная | Смысл | По умолчанию |
|---|---|---|
| `CV_HOST` | адрес прослушивания | `127.0.0.1` |
| `CV_PORT` | порт | `8765` |
| `CV_MODEL` | путь к модели (.pt/.onnx). Пусто → заглушка | — |
| `CV_STUB_COUNT` | сколько «кристаллов» рисует заглушка | `40` |

## API
- `GET /health` — статус, детектор, устройство.
- `GET /model` — метаданные детектора.
- `POST /infer` — форма: `image` (файл кадра). Query: `tiles` (по умолч. 6), `conf`, `iou`, `overlap`.
  Ответ: `{ image:{w,h}, count, objects:[{bbox,conf,polygon}], timing }`.
  Координаты объектов — в пикселях ИСХОДНОГО кадра. Измерения (мкм, группы) считает основной app.

## Несколько машин распознавания (Буи / Кир)
Ставится на каждую машину, где есть GPU и камера. На Кир (второй завод) — при переносе,
после отладки на Буи. Основной `web_MVS` на каждой машине смотрит на свой локальный сайдкар.
